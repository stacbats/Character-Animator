# Color Modes Quick Reference - Cheat Sheet

## 🎯 Color Modes at a Glance

### HI-RES Mode ✓
```
✓ 2 Colors Total
✓ Background + 1 Block Color
✓ Classic C64 High-Resolution
✓ Maximum Contrast
✓ Perfect for Symbols/Icons
✓ File Size: Smaller

Example: Black + White
```

### MULTI-COLOR Mode ✓
```
✓ 4 Colors Total
✓ Background + 3 Colors
✓ Authentic C64 Multi-Color
✓ More Detail & Personality
✓ Perfect for Characters
✓ File Size: Slightly Larger

Example: Black + Red + Yellow + Cyan
```

## ⚡ 30-Second Setup

### Step 1: Choose Mode
```
Left Panel → Color Mode
○ HI-RES (2 colors)
● MULTI-COLOR (4 colors)  ← Click
```

### Step 2: Set Colors
```
Left Panel → Color Scheme
Click the color squares
Choose colors from popup
```

### Step 3: Paint
```
Select color from palette
Paint your tile!
Only your scheme colors shown
```

## 🔄 How to Switch Modes

```
1. Click new mode radio button
2. Colors appear in scheme panel
3. Click color boxes to change them
4. Click Full Palette color to paint
5. Done! Existing pixels preserved
```

## 🎯 Color Slot Reference

### HI-RES Slots
```
Slot 1: Background (usually Black)
Slot 2: Block Color (usually White/Yellow/etc.)
```

### MULTI-COLOR Slots
```
Slot 1: Background (usually Black)
Slot 2: Color 1 (main - like clothing)
Slot 3: Color 2 (accent - like hair)
Slot 4: Color 3 (highlight - like eyes)
```

## 🚨 Common Gotchas

```
❌ "My color isn't available"
✓ It's not in your current scheme
✓ Click Color Scheme to add it

❌ "Colors changed when I switched modes"
✓ Normal! Each mode has its own colors
✓ Both are saved separately

✓ Not in this mode!
```

## 🎁 Tips & Tricks

### Tip 1: Save Multiple Versions
```
Save as:
- my_char_hi_res.c64 (HI-RES version)
- my_char_multi.c64 (MULTI-COLOR version)
Then compare!
```

### Tip 2: Progressive Enhancement
```
1. Create in HI-RES (simple)
2. Load, switch to MULTI-COLOR
3. Add color details
4. Save enhanced version
```

### Tip 3: Color Cycling
```
Frame 1: Black + Red + Yellow + White
Frame 2: Black + Red + White + Yellow (swapped)
Frame 3: Black + White + Yellow + Red (swapped)
Animation: Colors appear to cycle!
```

### Tip 4: Preview in Both Modes
```
1. Finish tile in MULTI-COLOR
2. Switch to HI-RES
3. Set to best 2 colors
4. See simplified version
5. Decide which you prefer
```
