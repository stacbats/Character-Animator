## 🎨 What You Can Create

### 8x8 Tiles (Classic)
- Original Commodore 64 character size
- Perfect for retro game sprites
- Simple animations (3-4 frames)
- Example: Running character, blinking eyes

### 16x16 Tiles (Medium)
- Double resolution for more detail
- Better for complex designs
- Smooth animations (5-8 frames)
- Example: Character portrait, enemy variations

### 32x32 Tiles (Large)
- High detail capabilities
- Full animation sequences
- Complex scene elements
- Example: Boss character, detailed backgrounds

## 💡 Tips

**First Time?**
- Start with 8x8 tiles
- Use bold colors for contrast
- Create 3-4 animation frames
- Zoom in to 20x for detailed work

**Saving Work?**
- Save frequently (every 5-10 min)
- Use descriptive filenames
- Keep backups
- .c64 files are portable

**Animation Tips?**
- 100-150ms is usually good speed
- Minimal changes between frames = smooth motion
- Test animation speed before saving
- 4-8 frames creates natural motion
